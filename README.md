# 极光AI

Vue 3 前端。技术栈：Vue 3 + TypeScript + Vite + Pinia + Vue Router + Element Plus + UnoCSS + Axios。

对话页素材：`docs/边界AI/新对话.html`。

## 快速开始

```sh
pnpm install
pnpm dev
```

默认开发地址：`http://localhost:5173`。请求 `/api` 会代理到 `http://localhost:8081`。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `pnpm dev` | 开发热更新 |
| `pnpm build` | 类型检查 + 生产打包 |
| `pnpm preview` | 预览打包结果 |
| `pnpm format` | 格式化 `src/` |
