## 0. 现状关键问题（写清单前先钉死）

| 现状 | 影响 |
| --- | --- |
| 全局只有一个 `streaming` + 一个 `AbortController` | 同时只能跑一路生成 |
| `newChat()` / 切换会话会调用 `stopStream()` | **新建对话会打断上一条**，无法后台等结果 |

## 3. 改进项明细（按优先级）

### P0 — 必须补齐

#### P0-0 停止 / 暂停生成（独立控件）

**目标**

1. 流式或生图进行中，输入区右侧明确展示 **停止** 按钮（方形停止图标，勿再用「上箭头发送」兼停）。
2. 点击停止后：
   - Abort 当前请求；
   - **保留已流出的文本 / 已出图**；
   - 气泡标记「已停止生成」；
   - 输入区恢复可发送。
3. 「暂停」若产品定义为「暂停后可续写」：多数上游不支持真正 resume，建议产品文案用 **「停止」**，勿承诺可续传；若未来上游支持，再加「继续」。
4. 键盘：可选 `Esc` 停止当前生成（焦点在对话区时）。

**验收**

- [x] 生成中可见独立停止钮  
- [x] 停止后内容不丢失、可复制  
- [x] 停止不会误删用户消息  

> 2026-10-14 已落地：Composer 独立停止钮 + Esc 停止；文案用「停止」不承诺续写。

---

#### P0-1 新建对话 / 切换会话时，上一会话后台继续（核心）

**问题**  
当前 `newChat()`、打开其他会话都会 `stopStream()`，用户无法「先开新聊，等旧的出完再回来看」——豆包等产品的基本能力。

**目标体验**

1. **新建对话**：立即进入空白会话，**不中断**上一会话正在进行的流式/生图请求。
2. **切换历史会话**：可查看其他会话；被切走的会话若仍在生成，**继续跑完并落库**。
3. 后台完成后：
   - 侧栏对应会话显示完成态（或短暂「新」角标）；
   - 若用户仍停留在该会话，实时追加内容；
   - 若用户在别的会话，回来打开时看到完整结果（依赖落库 + 可选轻量推送/轮询）。
4. **同一会话内**仍保持「同时只跑一路」：同一 session 未结束前禁止再发（或排队），避免消息顺序错乱。
5. 用户对某会话点「停止」：只停该会话任务，不影响其他后台任务。

**建议架构**

| 概念 | 说明 |
| --- | --- |
| `GenerationJob` | `{ sessionId, messageId, abortCtrl, kind: 'chat'\|'image', status }` |
| `jobRegistry` | `Map<sessionId, GenerationJob>`，支持多会话并行 |
| UI 绑定 | 当前页只订阅 `currentSessionId` 对应 job 的 delta；其他 job 只写 store / 落库 |
| 离开页面 | `beforeunload` 提示「仍有 N 个任务进行中」（可选）；尽量用 `keepalive`/落库保证结果不丢 |
| 后端 | 现有 SSE 按请求即可；关键是前端不要全局 abort。落库仍走 `appendChatMessages` |

**侧栏状态**

- 生成中：会话标题旁转圈 / 「生成中」
- 失败：红色小点，点开可见错误文案
- 刚完成且未读：小蓝点，打开后清除

**验收**

- [x] A 会话生成中 → 点「新建对话」→ A 不中断，B 可继续发问  
- [x] A 后台完成后，打开 A 能看到完整回复（含生图 URL）  
- [x] 对 A 点停止，只停 A，B 不受影响  
- [x] 刷新页面后：已落库内容仍在；未完成的请求会丢（可接受，文档标明）；后续可做「服务端任务」增强  

> 2026-10-14 已落地：`useGenerationJobs` + 按会话 `messageBags`；侧栏生成中/失败/未读角标。

#### P0-2 生图占位图 + 加载动效

**问题**  
生图耗时长，仅文案导致气泡高度跳动、体感差。

**目标**

1. 发送后立即出现 **与目标尺寸同比例** 的占位卡（按 `imageSize` 映射 aspect-ratio）。
2. 固定占位视觉资源 + **加载动效**（shimmer / 呼吸；尊重 `prefers-reduced-motion`）。
3. 文案：「正在绘制…」。
4. 成功：替换为真图；失败 / 停止：移除占位并提示。
5. 多图时按数量铺占位网格。

**建议**：组件 `ImageGenPlaceholder.vue`；消息增加 `status: 'generating'|'done'|'error'|'stopped'`。

**验收**

- [x] 100ms 内可见占位且比例正确  
- [x] 成功/失败/停止三种结局正确  
- [x] 历史打开的完成图不再显示加载态  

> 2026-10-14 已落地：`ImageGenPlaceholder.vue`；成图支持灯箱预览 / 下载 / 再生成；消息复制与重新生成；首字三点等待。

#### P0-4 消息级操作

助手消息（生成结束后）：

- 复制全文（Markdown 原文）
- 重新生成（移除本条 assistant，用上一轮 user 再请求；若该会话有后台 job 需先处理冲突）
- （可选）赞 / 踩打点

用户消息：复制；编辑重发见 P1。
